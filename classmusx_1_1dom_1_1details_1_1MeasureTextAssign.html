Detailed Description

Represents a text block assignment for a staff and measure.

Cmper1 is the staff (staffId) Cmper and Cmper2 is the measure Cmper.

Note that each instance either has a positive horizontal displacement in Edu, meaning it maintains metrical alignment as spacing changes. Or it has a negative horizontal displacement in Evpu, meaning a negative offset maintains its displacement in any spacing context.

The UI interpolates these values and shows different numbers to the user, but the actual origin point where both xDispEdu and xDispEvpu are zero coincides with Edu position 0.

This class is identified by the XML node name "measTextAssign".
