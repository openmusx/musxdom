◆ calcEduFromEvpu()

Edu musx::dom::others::Measure::calcEduFromEvpu ( Evpu  evpuFromLeftEdge,
BeatChartJustification  justification = BeatChartJustification::Modern,
bool  allowNegative = false 
) const

Converts a horizontal offset from the measure's left edge to an integral global Edu position.

Uses the measure's positioning mode, front/back spacing and extras, and justified beat-chart spans. Justified positions and interpolated durations are rounded to nearest integers, half away from zero. Positions beyond the music area extrapolate along the last span. A position before a span's start returns that span's Edu, except before the initial beat or pickup, where it returns the negative Evpu distance from that start. With no usable chart, conversion is proportional to measure duration.

Parameters
evpuFromLeftEdgeThe horizontal offset from the measure's left edge, in Scroll View.
justificationThe beat-chart justification algorithm.
allowNegativeWhether offsets before the music area's origin may produce negative positions. Otherwise such offsets return zero, before the chart is consulted.
Returns
The rounded Edu position. Zero-duration measures return zero; zero-width linear conversion returns the offset from the music area's origin.
