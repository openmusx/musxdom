Detailed Description

Represents the attributes of a page in the page layout.

This class is identified by the XML node name "pageSpec".

Member Function Documentation

◆ isLayoutCalculated()

bool musx::dom::others::Page::isLayoutCalculated ( ) const
inline

Returns whether this page has a calculated layout.

Blank pages are valid calculated pages. A nonblank page is calculated when its system range and corresponding measure range were resolved by calcSystemInfo.
