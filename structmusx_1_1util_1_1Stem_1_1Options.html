Empty callbacks use document metrics and saved staff positions. Resolver exceptions propagate to the caller.

std::function<GeometryResult(const dom::EntryInfoPtr&)> musx::util::Stem::Options::geometryResolver

Optional resolver invoked for each entry whose geometry is requested.

Offset supplies complete musx::util::Stem::Geometry and bypasses the staff-origin resolver and document geometry for that entry. NotHandled uses document metrics and staffOriginOffsetResolver. Unavailable produces #Resolution::MissingGeometry. The note-position array must match the original entry's note count; part-voicing exclusions still apply. Null note elements affect geometric participation, not stem assignments. The embedded resolution is honored; an included note with no vertical position is MissingGeometry. Complete geometry supplied here is reported as Caller provenance regardless of its embedded source.

◆ staffOriginOffsetResolver

StaffOriginOffsetResolver musx::util::Stem::Options::staffOriginOffsetResolver

Optional resolver for cross-staff origin offsets when complete geometry is not supplied.

Offsets are downward-positive EVPU, as returned by the layout helpers, before normalization to source-staff scale. NotHandled uses the saved-system proxy, which falls back to Scroll View only when no system staff list is available. Unavailable prevents fallback. Document staff scaling still applies.
