◆ calcSlurContour()

CurveContourDirection musx::dom::others::ShapeDef::calcSlurContour ( ) const

Determine the slur contour orientation, if this shape is a slur/tie.

Uses StartObject bounding boxes to determine whether the contour arches upward or downward. Returns CurveContourDirection::Down or ::Up when determinable, otherwise ::Auto when the instructions do not represent a slur/tie or Finale's sentinel bounds appear.

◆ calcWidth()

std::optional< Evpu > musx::dom::others::ShapeDef::calcWidth ( ) const

Calculate the width of the shape in Evpu, if it can be determined.

The width is derived from stored StartObject/StartGroup bounding boxes. Shapes that include text instructions or Finale's sentinel bounding boxes (INT32 min/max markers) return std::nullopt because the true extents would require replaying the drawing instructions with Finale's rendering context.

Returns
The width in Evpu or std::nullopt if it cannot be computed.
