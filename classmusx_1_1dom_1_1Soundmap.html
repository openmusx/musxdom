◆ findInstrumentSoundRef()

std::string_view musx::dom::Soundmap::findInstrumentSoundRef ( std::string_view instrumentUuid) const
nodiscard

Finds the sound id that <MapSounds> assigns to an instrument.

The instrument UUID is trimmed and matched case-insensitively. When more than one <MapSounds> names the instrument, the first in file order is used. When it lists more than one <Sound ref>, the first is used.

Parameters
instrumentUuidThe instrument UUID.
Returns
The trimmed sound id, or empty if the soundmap does not map the instrument.

const std::vector< std::string > & musx::dom::Soundmap::getInstrumentSoundRefs ( std::string_view instrumentUuid) const
nodiscard

Returns every sound id that <MapSounds> assigns to an instrument.

Each <MapSounds> naming the instrument contributes its first <Sound ref>, in file order. The instrument UUID is matched as in findInstrumentSoundRef.

Parameters
instrumentUuidThe instrument UUID.
Returns
