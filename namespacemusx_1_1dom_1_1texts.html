template<typename T>
std::optional< Cmper > musx::dom::texts::importTextInto ( const DocumentPtr & target,
const MusxInstance< T > & source,
const ImportObjectCallback & onImported )
nodiscard

Copies a raw text string into another document.

The copy retains source's concrete text type and is created at score scope with EnigmaBase::ShareMode::All. It receives that type's next free text number in target. The exception is FileInfoText, whose number identifies its semantic type and is therefore retained; importing fails if that type is already present. Derived lyric syllable information is rebuilt for copied lyric text.
