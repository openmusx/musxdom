Detailed Description

Options controlling text rendering in the musx file. Many of these options are default values that are inserted into Enigma tags when a page or measure text is created. Others are default values for the assignment. As such, once a page or measure text has been created, it does not change even if these default values change.

This class is identified by the XML node name "textOptions".
