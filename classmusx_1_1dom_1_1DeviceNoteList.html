Detailed Description

One named note-name list from a supplied MIDI Device Annotation file.

Each entry pairs a 0-based MIDI key with a full PercussionNoteTypeId, including any order ID in its top four bits. Rows whose key is outside 0..MAX_MIDI_KEY or whose base note type is not a known percussion note type are omitted.
