Detailed Description

Soundmaps, MIDI Device Annotation note-name lists, and instrument catalog entries supplied by the caller.

Create instances with musx::factory::PlaybackResourcesFactory. An instance is immutable and may be shared and used concurrently.

Name matching rules:

  • UUIDs are trimmed and matched case-insensitively.
  • Sound ids, sound refs, plugin IDs, and list names are trimmed and matched exactly.
  • Device file names are reduced to their final path component (after the last / or \\endiskip) and matched exactly.

Duplicates resolve to the first supplied: the first soundmap (in caller order) with a sound UUID, the first sound in a soundmap with an id, and the first device file and list with a given file name and list name.

When no resources at all were supplied, every lookup fails with PlaybackLookupFailure::ResourcesNotSupplied.

Finds the sound that <MapSounds> assigns to an instrument for a playback plugin.

Soundmaps whose plugin ID matches pluginId are searched in caller order. Within each, the instrument's sound refs are tried in file order (see Soundmap::getInstrumentSoundRefs), and the first ref that names one of the soundmap's sounds selects that sound. If the selected sound has a non-empty UUID it is the result; otherwise the search continues with the next soundmap.

Parameters
pluginIdThe plugin ID to match against SoundmapDescription::pluginId. An empty plugin ID matches no soundmap.
instrumentUuidThe instrument UUID.
Returns
The sound, or PlaybackLookupFailure::SoundNotFound.
