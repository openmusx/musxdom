dom::PlaybackResourcesPtr musx::factory::PlaybackResourcesFactory::create ( const PlaybackResourceInputs & inputs)
inlinestaticnodiscard

Parses playback resource files with the selected XML backend.

Files with no bytes are skipped. Inputs with no files produce an empty resource object. The returned object does not refer to the input bytes.

Template Parameters
XmlDocumentTypeThe xml::IXmlDocument implementation used to parse the files.
Parameters
inputsThe files to parse.
Returns
The immutable resources.
Exceptions
