Detailed Description

An array of StaffUsed defines a set of staves in a staff system or in Scroll View.

The cmper is either BASE_SYSTEM_ID (for Scroll View) or the SystemCmper of a system. There are some other special cmper values as well for staff sets in Scroll View or Special Part Extraction or Studio View.

This class is identified by the XML node name "instUsed".
