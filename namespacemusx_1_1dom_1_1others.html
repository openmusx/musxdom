◆ importShapeDefInto()

std::optional< Cmper > musx::dom::others::importShapeDefInto ( const DocumentPtr & target,
const MusxInstance< ShapeDef > & source,
const ImportObjectCallback & onImported = {} )
nodiscard

Copies a shape and everything it owns into another document.

A shape is more than its ShapeDef: the instruction list and data list it names are separate objects in their own pools, and a SetFont instruction inside the data names a font. Each is copied to the next free cmper in its own pool of target, and the copied ShapeDef is rewired to the new numbers. Font references are resolved by importFontDefinitionInto, so a copied shape never names a font by source's cmper.

Nothing is added to target unless the whole shape can be copied. Font definitions resolved along the way are an exception and may remain, which is harmless: an unreferenced definition changes no rendering.

Parameters
targetThe document to import into. May be the same document as source's.
sourceThe shape to import.
onImportedCalled for the shape and every dependency this operation creates.
Returns
The ShapeDef cmper within target, or std::nullopt when a pool has no free cmper left, when the source is missing its instruction or data list, or when a font it names cannot be resolved.
Exceptions
std::invalid_argumentif target or source is null. Debug builds assert instead.

Copy embedded graphics, so that a shape containing an ExternalGraphic instruction can be imported rather than refused.
Todo
Copy the embedded graphic and remap the cmper, as is done for fonts below.

◆ importSmartShapeCustomLineInto()

std::optional< Cmper > musx::dom::others::importSmartShapeCustomLineInto ( const DocumentPtr & target,
const MusxInstance< SmartShapeCustomLine > & source,
const ImportObjectCallback & onImported = {} )
nodiscard

Copies a custom line and its document-local dependencies into another document.

The copied line receives the next free SmartShapeCustomLine cmper in target. Character fonts, custom arrowhead shapes, and raw Smart Shape text strings are copied or resolved through importFontDefinitionInto, importShapeDefInto, and texts::importTextInto. The new line is rewired to their target-document cmpers. Repeated references to one source dependency share one imported target object.

Nothing is added to the SmartShapeCustomLine pool unless every dependency can be resolved. Successfully imported dependencies may remain when a later dependency cannot be imported; unreferenced fonts, shapes, and raw text strings do not affect rendering.

Parameters
targetThe document to import into. May be the same document as source's.
sourceThe custom line to import.
onImportedCalled for the custom line and every dependency this operation creates.
Returns
The copied line's cmper within target, or std::nullopt when a destination pool has no free cmper or a referenced source object cannot be resolved.
Exceptions
std::invalid_argumentif target or source is null. Debug builds assert instead.
