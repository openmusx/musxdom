Detailed Description

Assigns an articulation to an entry.

#Entry::articDetail is set if the entry has any articulations.

◆ calcHandleHorizontalOffset()

std::optional< double > musx::dom::details::details::ArticulationAssign::calcHandleHorizontalOffset ( const EntryInfoPtr & entryInfo) const
nodiscard

Calculates the primary handle's horizontal offset from the entry's drawing origin in EVPU, positive rightward.

Assignment and selected-symbol definition offsets are additive. The result is not a notehead center, a visible glyph edge, or an association with a note. No staff-space conversion or resizing is applied. Automatic vertical positioning is supported when the selected symbol is certain or both symbols have equal horizontal offsets. A returned coordinate does not certify the selected character; consult SelectedSymbolContext::symbolIsEstimate separately when identifying symbols.

Parameters
entryInfoA non-null context for this assignment's entry, document, and requested part.
Returns
The handle offset, or std::nullopt for horizontal auto-positioning, stem centering, symbol copying, or uncertain symbol selection with unequal main and alternate horizontal offsets.
Exceptions
std::logic_errorif entryInfo is null or does not match this assignment's context.
integrity_errorif the required definition is missing, when integrity exceptions are enabled. Otherwise the missing definition is logged and returns std::nullopt.

◆ calcHandleStaffPosition()

std::optional< double > musx::dom::details::details::ArticulationAssign::calcHandleStaffPosition ( const EntryInfoPtr & entryInfo) const
nodiscard

Calculates the primary handle's fractional staff position for a manually positioned articulation.

Positions are relative to the entry staff's reference line, positive upward; one unit is half the current staff line spacing. The reference note is selected by #others::ArticulationDef::useTopNote. Assignment and selected-symbol vertical offsets are additive. The definition's default vertical position does not contribute. Staff and entry size percentages do not affect the result. This is a handle coordinate, not a glyph center or an association with a note.

Parameters
entryInfoA non-null context for this assignment's entry, document, and requested part.
Returns
The handle position, or std::nullopt for automatic placement, placement overrides, symbol copying, outside-staff or staff-line avoidance, slur avoidance, rests, empty entries, grace notes, cross-staff notes, nonstandard notation styles, alternate notation, active part voicing, or vertically displaced noteheads.
Exceptions
std::logic_errorif entryInfo is null or does not match this assignment's context.
integrity_errorif required definition/staff data is missing or staff line spacing is nonpositive, when integrity exceptions are enabled. Otherwise these failures are logged and return std::nullopt.

◆ calcSelectedSymbolContext()

std::optional< details::ArticulationAssign::SelectedSymbolContext > musx::dom::details::details::ArticulationAssign::calcSelectedSymbolContext ( const EntryInfoPtr & entryInfo) const
nodiscard

Resolves the symbol information used by this articulation assignment on the specified entry.

Copied articulations use the main character, font, and offsets. Otherwise selection is exact when both sides select the same symbol, or for manual vertical positioning without outside-staff or staff-line avoidance. Manual selection compares the assignment offset with zero, treating equality as above, before applying symbol offsets; placement overrides do not change this comparison. Other cases use a policy-based estimate and set SelectedSymbolContext::symbolIsEstimate. Automatic positioning, avoidance, and dragging may change Finale's final selection.

Returns
The resolved symbol context, or std::nullopt if the entry context or articulation definition cannot be resolved.
